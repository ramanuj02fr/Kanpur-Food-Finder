# Kanpur Food Finder

A simple data-collection form for cataloguing local food places in Kanpur — name, category, dishes tried with prices, ambience, and location (captured live via GPS, or typed in when adding from memory).

Data is stored in Firebase Firestore under the `places` collection.

## Deploy

```
npm install -g firebase-tools
firebase login
firebase deploy
```

Live site: https://kanpur-food-finder.web.app
